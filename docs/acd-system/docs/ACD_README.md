## 🌟 AROS Extensions to ACD Standard

The AROS project extends the official ACD standard with:

### 1. Dual-Agent Communication Protocol
**Purpose:** Enable two LLM agents to collaborate using ACD as exchange of thought

**Components:**
- **Communication Flags** - 11 flags across 3 categories (confidence, request, state)
- **Exchange Protocol** - 4-phase workflow (generate → reason → refine → validate)
- **Agent Coordination** - Generator and reasoner agents working together

**Documentation:** [DUAL_AGENT_SYSTEM.md](DUAL_AGENT_SYSTEM.md)

### 2. Extended ACD Tags

**New Tags for Dual-Agent Exchange:**
- `AI_VALIDATION` - Validation status from reasoner
- `AI_ISSUES` - Issues identified by reasoner
- `AI_SUGGESTIONS` - Suggestions from reasoner
- `AI_REFINEMENT` - Refinement status
- `AI_CHANGES` - Changes made during refinement
- `AI_RATIONALE` - Reasoning for changes
- `AI_VALIDATION_RESULT` - Final validation result
- `AI_APPROVAL` - Approval status

### 3. Communication Flags System

**Confidence Flags:** CONFIDENT, UNCERTAIN, HYPOTHESIS  
**Request Flags:** REQUEST_FEEDBACK, WAITING_FOR_INPUT, NEEDS_VALIDATION  
**State Flags:** PROCESSING, READY, DONE, BLOCKED

### 4. Implementation Tools

**Dual-Agent Orchestrator:**
- `scripts/dual_agent_orchestrator.py` - Coordinates generator and reasoner agents
- Automatic integration with autonomous build agent
- Smart routing of complex errors to dual-agent system

**Configuration:**
- `llm_config.yaml` - Complete dual-agent configuration
- GPU allocation and model selection
- Exchange protocol parameters

### 5. Integration Points

**Autonomous Build Agent:**
- Automatic routing of complex errors to dual-agent
- Graceful fallback to single-agent
- Complete logging of exchange history

**Quick Start:**
```bash
# Use dual-agent for build errors (automatic)
python3 scripts/autonomous_build_agent.py

# Use dual-agent explicitly
python3 scripts/dual_agent_orchestrator.py \
    --problem "Your problem description" \
    --output results.json

# Run examples
python3 scripts/dual_agent_example.py
```
