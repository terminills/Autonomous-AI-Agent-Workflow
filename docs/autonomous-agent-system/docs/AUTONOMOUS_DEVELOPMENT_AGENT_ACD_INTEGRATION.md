## How the Agent Uses ACD Breadcrumbs

### 1. Reading Breadcrumbs (Semantic Understanding)

The agent builds an **indexable context memory map** from ACD breadcrumbs:

```python
# At startup, the agent scans the codebase
agent.build_acd_context_map()

# This creates indices:
# - phase_index: Maps AI_PHASE -> files
# - status_index: Maps AI_STATUS -> files  
# - context_map: Full metadata for each file
```

**What this enables:**

- **Semantic Code Navigation**: Find related files via `AI_DEPENDENCIES`
- **Phase Tracking**: Know which components are in which development phase
- **Status Awareness**: Identify PARTIAL, BROKEN, or IMPLEMENTED code
- **Intelligent Error Analysis**: Find related code when fixing errors
- **Complexity Assessment**: Understand code difficulty levels

### 2. Writing Breadcrumbs (Self-Documentation)

The agent generates ACD breadcrumbs in **all code it creates**:

#### Generated Function Example:

## ACD Spec Tags Generated

The agent uses the **full enhanced ACD specification**:

| Tag | Usage | Example |
|-----|-------|---------|
| `AI_PHASE` | Development phase | IMPLEMENTATION, ERROR_CORRECTION, PORT_INTEGRATION |
| `AI_STATUS` | Implementation state | IMPLEMENTED, PARTIAL, BROKEN, FIXED |
| `AI_COMPLEXITY` | Code complexity | LOW, MEDIUM, HIGH, VERY_HIGH |

| `AI_COMMIT` | Commit identifier | "agent_20251030_133244" |
| `AI_GENERATED` | Agent-created flag | TRUE |
| `AI_TIMESTAMP` | Creation time | ISO 8601 timestamp |

## Workflow: How ACD Integration Works

### Phase 0: Build Context Map
```
[Agent Start]
    ↓
[Scan repository for AI_PHASE, AI_STATUS, AI_DEPENDENCIES tags]
    ↓
[Build indices: phase_index, status_index, context_map]
    ↓
[Context Map Ready] ← Semantic memory available
```

### Phase 1: Intelligent Error Analysis
```
[Build Error Detected]
    ↓
[Extract error info: file, line, message]
    ↓
[Query ACD context map]
    ↓
[Find related files via AI_DEPENDENCIES]
    ↓
[Check AI_STATUS of related files (PARTIAL? BROKEN?)]
    ↓
[Generate ACD-aware fix suggestion]
```

### Phase 2: Code Generation
```
[Need to fix/create code]
    ↓
[ACDCodeGenerator.generate_*()]
    ↓
[Add AI_PHASE tag (e.g., ERROR_CORRECTION)]
    ↓
[Add AI_STATUS tag (e.g., FIXED)]
    ↓
[Add AI_COMPLEXITY, AI_NOTE, AI_STRATEGY]
    ↓
[Add AI_GENERATED: TRUE, AI_TIMESTAMP]
    ↓
[Generated code with full breadcrumbs] ← Self-documenting
    ↓
[Code becomes part of context map for future]
```

## Benefits of ACD Integration

### 1. **Semantic Memory**
The agent "remembers" codebase structure through breadcrumbs, not just file names.

### 2. **Intelligent Navigation**
Finds related code via `AI_DEPENDENCIES`, not just grep/search.

### 3. **Context-Aware Fixes**
Generates fixes that match the complexity and phase of surrounding code.

### 4. **Self-Documenting Code**
All generated code explains its purpose, status, and dependencies.

### 5. **Traceability**
Every change has `AI_COMMIT` and `AI_TIMESTAMP` for audit trail.

### 6. **Phase Tracking**
Can query: "Show me all PARTIAL implementations" or "Find BROKEN code"

### 7. **Dependency Understanding**
Knows which components depend on which through breadcrumbs.

### 8. **Iterative Improvement**
Each generated code adds to context map, improving future operations.

## Example: Error Fixing with ACD Context

**Scenario:** Build error "undefined reference to `initialize_buffer`"

**Without ACD:**
```
1. See error
2. Search for "initialize_buffer"
3. Guess where to add it
4. Add function (no context)
```

**With ACD:**
```
1. See error: undefined reference to `initialize_buffer`
2. Query ACD context map for error file
3. Find AI_DEPENDENCIES: "BUFFER_MANAGEMENT, MEMORY_POOL"
4. Find related files with BUFFER_MANAGEMENT phase
5. Check their AI_STATUS (are they PARTIAL? BROKEN?)
6. Generate fix with matching AI_COMPLEXITY
7. Add breadcrumbs:
   // AI_PHASE: ERROR_CORRECTION
   // AI_STATUS: FIXED
   // AI_NOTE: Added missing initialize_buffer function
   // AI_DEPENDENCIES: MEMORY_POOL
8. Fix becomes part of context map for future
```

## Key Classes

### ACDBreadcrumbAnalyzer
- **Purpose**: Read and index ACD breadcrumbs
- **Methods**:
  - `parse_file_breadcrumbs()` - Extract tags from file
  - `scan_directory()` - Build context map
  - `find_by_phase()` - Query by AI_PHASE
  - `find_by_status()` - Query by AI_STATUS
  - `find_related_files()` - Follow AI_DEPENDENCIES

### ACDCodeGenerator
- **Purpose**: Generate code with ACD breadcrumbs
- **Methods**:
  - `generate_breadcrumb_header()` - Create tag header
  - `generate_function_with_breadcrumbs()` - Function stub
  - `generate_fix_with_breadcrumbs()` - Error fix
  - `generate_port_skeleton()` - Port template

### AutonomousDevelopmentAgent
- **Uses both**: Reads context, generates code
- **Methods**:
  - `build_acd_context_map()` - Build semantic memory
  - `find_related_code_by_error()` - ACD-aware search
  - `generate_code_fix()` - Create fix with tags
  - `create_new_component()` - Component with tags
