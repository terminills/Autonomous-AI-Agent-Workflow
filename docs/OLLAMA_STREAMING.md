# Ollama Streaming and ACD Scanning Improvements

## Overview

This document describes the improvements made to the AROS autonomous development agent to provide better visibility into:
1. **Real-time Ollama LLM thoughts** - See what the AI is thinking as it happens
2. **Comprehensive repository scanning** - Full codebase exploration with ACD augmentation

## Problem Statement

### Issue 1: No Visibility into Ollama Thoughts
**Before**: The autonomous agent would call Ollama but only show generic status messages like "Consulting LLM..." with no insight into the actual reasoning process.

**Why this matters**: Users couldn't see what the AI was actually thinking, making it difficult to:
- Understand the reasoning process
- Debug when the AI made mistakes
- Learn from the AI's approach
- Trust the AI's decisions

### Issue 2: Limited Scan Coverage
**Before**: The ACD scanner only scanned ~43 files in a few specific directories, giving the impression that ACD *replaced* rather than *augmented* code exploration.

**Why this matters**: Users couldn't see:
- How much of the codebase had semantic annotations
- Which files lacked ACD metadata
- The true scope of the repository
- That ACD was meant to augment, not replace exploration

## Solutions Implemented

### 1. Real-Time Streaming of Ollama Thoughts

#### Implementation
The `OllamaBackend` class in `llm_backends.py` now supports streaming mode:

```python
# New streaming callback interface
def stream_callback(token, is_thinking):
    """Called for each token generated by Ollama.
    
    Args:
        token: The generated text token
        is_thinking: True if this is a reasoning/thinking token,
                     False if it's code generation
    """
    if is_thinking:
        print(f"🤔 {token}", end='', flush=True)  # Thinking
    else:
        print(f"💡 {token}", end='', flush=True)  # Generating
```

#### Usage Example
When the autonomous agent calls Ollama for error analysis:

```python
# In autonomous_build_agent.py
llm_suggestion = self.llm_backend.generate(
    prompt=prompt,
    max_tokens=500,
    temperature=0.7,
    enable_reasoning=True,
    stream_callback=stream_callback  # Enable streaming!
)
```

#### What You'll See
```
🧠 Ollama thoughts (streaming):
🤔 Let me analyze this error...
🤔 The undefined reference suggests...
💡 Here's the fix:
💡 Add the missing function declaration...
```

## Technical Details

### Streaming Protocol
Ollama's streaming API returns JSON objects line-by-line:
```json
{"model":"qwen2.5-coder:72b","response":"Let me","done":false}
{"model":"qwen2.5-coder:72b","response":" analyze","done":false}
{"model":"qwen2.5-coder:72b","response":"...","done":true}
```

The `_handle_streaming_response()` method:
1. Opens HTTP connection to Ollama API
2. Reads response line-by-line
3. Parses each JSON chunk
4. Detects thinking vs. generation patterns
5. Calls the stream callback for each token
6. Accumulates full response
7. Returns complete text when done

### Thinking Detection
The code detects "thinking" tokens by looking for patterns:
```python
is_thinking = any(marker in response_text.lower() for marker in 
                 ['thinking:', 'reasoning:', 'let me', 'i need to'])
```

This heuristic works well for models like Qwen that use explicit reasoning markers.

### Scanning Algorithm
The comprehensive scanner:
1. Walks repository tree recursively using `pathlib.glob()`
2. Filters by extension (.c, .h, .py, .cpp, .hpp, .sh)
3. Skips build artifacts (.git, bin/, build/, __pycache__)
4. Attempts to extract ACD breadcrumbs from each file
5. Indexes files with breadcrumbs in semantic index
6. Tracks non-ACD files in statistics
7. Reports comprehensive coverage metrics

## Configuration

### Enable Streaming (Default: On)
Streaming is automatically enabled when a `stream_callback` is provided:

```python
# Streaming enabled
backend.generate(prompt, stream_callback=my_callback)

# Streaming disabled
backend.generate(prompt)  # No callback = no streaming
```

### Control Verbosity
```python
# Show all progress
index = ACDSemanticIndex(repo_path, verbose=True)
scan_stats = index.scan_codebase(show_progress=True)

# Quiet mode
index = ACDSemanticIndex(repo_path, verbose=False)
scan_stats = index.scan_codebase(show_progress=False)
```
